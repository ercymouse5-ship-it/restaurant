# فرن الحارة — طلبات مباشرة على واتساب

واجهة عربية RTL لمطعم مشويات مصري. الزائر يختار أكلته، يراجع السلة وتكلفة المنطقة، ثم يرسل تفاصيل الطلب للمطعم على واتساب. التطبيق يعمل من غير Backend؛ رقم واتساب ومعلومات المطعم قابلة للتعديل من ملفات البيانات. هذه نسخة تجريبية؛ حدّث بيانات المطعم والعروض والتقييمات ورقم التواصل قبل استقبال طلبات حقيقية.

## التشغيل محلياً

من مجلد المشروع:

```bash
pnpm install                         # من جذر الـ workspace
pnpm --filter @workspace/mat3am-ordering run dev
```

للتأكد من TypeScript أو إنتاج نسخة static:

```bash
pnpm --filter @workspace/mat3am-ordering run typecheck
pnpm --filter @workspace/mat3am-ordering run build
```

افتح `/` لاختيار مطعم، أو `/furn-elhara` لعرض منيو فرن الحارة.

## إضافة مطعم

1. انسخ `src/data/restaurants/furn-elhara.ts` إلى ملف جديد باسم مناسب داخل `src/data/restaurants/`.
2. حدّث `slug`، معلومات الاتصال والعنوان، مواعيد العمل، مناطق التوصيل، الأقسام، الأصناف، العروض والتقييمات.
3. أضف الاستيراد والمطعم الجديد إلى `src/data/restaurants/index.ts` عشان يظهر في الصفحة الرئيسية.
4. أضف صور المطعم إلى مجلد `public/`، ثم حدّث `image` في الأصناف والكومبوهات.

تُعرّف كل قائمة مطعم باستخدام الأنواع الموجودة في `src/data/types.ts`. السعر بالجنيه المصري كرقم، ورقم واتساب بصيغة دولية من غير علامة `+` أو مسافات. مواعيد العمل تستخدم تنسيق 24 ساعة؛ حالة الفتح تُحسب بمنطقة `Africa/Cairo`.

## تخصيص الإعدادات

- رقم الطلبات: `whatsappNumber` في ملف المطعم، بصيغة دولية من غير `+` أو مسافات. الرقم الموجود في المثال تجريبي واستبدله برقمك.
- الاتصال والموقع: `phone` و`mapsLink` و`address`.
- ألوان الهوية: `theme` في ملف المطعم؛ تفاصيل الثيم العامة في `src/index.css`.
- صورة الغلاف: ضع الصورة في `public/` وحدّث مسار `photo` في ملف المطعم.
- رسوم التوصيل والحد الأدنى: عناصر `deliveryZones`.
- نص العرض وموعد انتهائه: `offerBanner`، و`endsAt` لازم يكون تاريخاً ووقتاً كاملاً بصيغة ISO.

## النشر مجاناً على Vercel

1. ارفع المشروع إلى GitHub، ثم استورده من لوحة Vercel.
2. اختَر جذر المستودع كمجلد المشروع.
3. استخدم إعدادات البناء التالية:
   - Install command: `pnpm install --frozen-lockfile`
   - Build command: `PORT=4173 BASE_PATH=/ pnpm --filter @workspace/mat3am-ordering run build`
   - Output directory: `artifacts/mat3am-ordering/dist/public`
4. انشر الموقع، وبعدها اختبر الصفحة الرئيسية ورابط المطعم مثل `/furn-elhara`.

ملف `vercel.json` يعيد توجيه روابط المطاعم إلى صفحة التطبيق حتى تعمل عند فتح الرابط مباشرة.

السلة وبيانات العميل تُحفظ محلياً على الجهاز. التأكيد يفتح رسالة واتساب جاهزة ومشفّرة؛ لا يتم إرسال الطلب تلقائياً قبل ضغط الزائر على التأكيد.
